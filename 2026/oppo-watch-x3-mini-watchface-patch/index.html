OPPO Watch X3 Mini 表盘魔改过程记录

我很喜欢 OPPO 表盘市场的「明晰组件」这个表盘，唯一的美中不足是，日期、星期和秒数都是灰色。暗光下还能看清，但在户外强光下对比度太低，几乎要凑近才能辨认。想把这几个元素改成白色。真正动手后才发现，它不是普通的 APK 表盘，而是 OPPO 的 engine 表盘包，而且主屏和抬腕/AOD 是两套完全不同的渲染资源。

本文记录一次在自家设备上的修改过程，不涉及绕过付费或分发修改后的表盘；如果你也想改自己买的表盘，可以参考思路。

一、它不是 APK

设备是 OPPO Watch X3 Mini（OWW263，Android 11）。「明晰组件」在 pm list packages 里找不到，dumpsys package 里也没有对应的 WatchFaceService，说明它不是独立安装的 APK。

它的真实身份是一个 engine 表盘 zip 包：

场景渲染方使用的资源
解锁后的主屏主 SoC 上的 uienginemanifest.json + images/

所以只改 manifest.json 会出现一个很典型的现象：解锁后是白色，抬腕还是灰色。两套资源都要改。

三、包结构

文件/目录作用
images/wf_pic_no_*.webp背景、时分秒数字、天气/电量等图层，按编号被 manifest.json 引用
images/preview.png / preview_small.png表盘选择器里的预览图
manifest.json主屏显示列表：每个图层的类型、坐标、颜色、字体、数据源
infos.json表盘元数据：packageName、versionCode、可编辑组件槽位
project.json设计工具生成的工程数据，运行时基本不用
mcu/bin/style0.binMCU 正常模式的显示列表（编译后）
mcu/bin/aod/style0.binMCU 的 AOD 版本显示列表
mcu/bin/preview.bin12 字节头（宽、高、类型、长度）+ PNG 预览图
mcu/bin/font_*.binMCU 位图字体，魔数 UFL$
mcu/bin/setting.bin / widget.binMCU 配置头和组件定义

style0.bin 不是文本配置，是编译后的二进制显示列表，魔数 78 56 34 12；颜色字段可以直接找出来改，但版式（坐标、字号、文本拆分）没有公开的编译器可用，这一点后面再说。

秒数不是文字，而是 WebP 数字精灵，像素本身是灰度 (125,125,125)。把这些图的非透明像素重绘成白色，保留 alpha：

五、装回手表

5.1 为什么不能直接 adb 安装

手表的 Launcher 有一个 EngineWfProvider（authority com.heytap.wearable.provider.watchfaces），安装表盘时需要向它写入 zip。但它的写入口做了校验：调用方必须是 OPPO 表盘商店（包名 com.heytap.wearable.themestore），并且证书 SHA-256 匹配。

adb shell 能通过 content call --method install_watchface 拿到安装 URI，但 content write 会被拒绝；普通第三方 App 连调用都返回 null。这条路走不通，正确做法是在手机同步给手表之前把 zip 换掉。

5.2 在同步瞬间替换

用 strace 观察手机的同步过程，顺序是：

  1. 下载进程用 O_WRONLY|O_CREAT|O_TRUNC 打开 Temp/Pkg/<包名>.zip 并写入
  2. 其他进程随后按路径重新 open(O_RDONLY) 读取
  3. 最后 unlink 删除

所以只要在文件刚被创建时，把我们的改色包原子 rename 覆盖到该路径即可。写进程手里的 fd 仍指向被 unlink 的旧 inode，它继续写它的；后面按路径打开的进程拿到的就是我们的文件。

有两个细节：

  • 等长：手机/手表会 stat 文件大小，最好让改色包和原包字节数完全一致。用最高压缩级别重打，再用 zip comment 补齐到原大小（本例 341427 字节）。
  • 同文件系统：临时文件必须放在目标目录内再 ATOMIC_MOVE。放在 /data/local/tmp 会报 Cross-device link。

六、结果

七、限制

主屏的版式（比如去掉 24H、把星期移到秒上方、日期改成上下排列、字号加大）在 manifest.json 里改起来很简单。但抬腕/AOD 用的是 MCU 的 style0.bin，这是编译后的显示列表：

  • 没有公开的编译器/反编译器
  • 不能从 manifest.json 重新生成
  • 手工改颜色可以，改坐标/字号/文本结构成本很高

如果只改主屏，就会出现主屏和 AOD 版式不一致。所以这次只做了颜色，版式保持原样，两边看起来一致。对「只想看清时间」来说，已经够了。
